# FXYN.DATA — Personal Portfolio

Pixel-art style personal portfolio of Muhamad Firmansyah, an Information Systems
student focused on data analysis, AI & machine learning, and data visualization.

Built as a fully static site (plain HTML, CSS, and JavaScript) with no build step
and no dependencies, so it can be hosted on any static host such as GitHub Pages.

## Run locally

```bash
python -m http.server 8000
# then open http://127.0.0.1:8000
```

## Structure

- `index.html` — single-page layout (home, profile, projects, achievements, contact)
- `style.css`, `modern.css`, `pixel-world.css`, `profile-nav.css` — styling layers
- `script.js`, `pixel-world.js`, `scroll-depth.js`, `scroll-scenes.js` — interactions
- `foto/` — portrait photos
- `seftifikat/` — certificate images shown in the achievements section
- `backsound/` — background audio track
